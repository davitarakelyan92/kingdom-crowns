# Icon tile backgrounds (r6)
Derived composites only. The original symbol art (art/sym2/*.jpg, identity/crown-hero.png) is never modified.
- materials/: one generated material ground per symbol (no objects). Wild: oxblood quilted velvet. Scatter: royal-blue velvet with gold thread. Crown: black velvet under a treasury spotlight. Sword: oxblood tooled leather. Shield: dressed stone panel. 7: blackened brushed steel. A: charcoal slate. K: navy tooled leather. Q: burgundy morocco leather. J: blue-grey marble. 10: aged bronze.
- masks/<k>.png: 1024² alpha for the source object. It combines a BiRefNet matte (rembg, `birefnet-general`) with a colour-difference matte against an inpainted studio clean plate. The colour-difference pass keeps the dark blue enamel that the model alone drops. Holes in A/Q/10 etc. stay transparent. Built by src/tile_masks.py (raw BiRefNet mattes in art/tilebg/mattes, made by src/tile_matte_birefnet.py with /workspace/tools/venv-rembg; run one key per process because of memory).
- tiles/<k>.png: material ground + soft contact shadow + original pixels. Pixels where alpha = 255 are copied exactly from the source. Partial edge pixels are colour-decontaminated against the local studio ground. The tile size equals the r4 CSS zoom crop, so framing matches r4. Built by src/tile_compose.py; per-symbol brightness, vignette and saturation live in its MAT table.
- src/gen.py `TILE` switches boards between r6 tiles and r4 (`TILE=None` reproduces r4 byte-identically).
